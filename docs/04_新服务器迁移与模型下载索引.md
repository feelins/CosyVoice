## 1. 从 git 能拿到什么、拿不到什么

| 内容 | git 里有吗 | 说明 |
|---|---|---|
| 代码（dev 分支） | ✅ | `11 MB` + `.git 3 MB`，很小 |
| 子模块 `third_party/Matcha-TTS` | ⚠️ 只有指针 | **必须** `git submodule update --init`，否则 `import matcha` 失败 |
| `pretrained_models/` | ❌ | `.gitignore` 里写了 `pretrained_models/*`，9.1 GB 全在本地 |
| `examples/teochew/data/*.parquet` | ❌ | `.gitignore` 的 `data` 规则挡住，243 MB |
| `teochew-data/`（原始 wav） | ❌ | 仓库外，479 MB |
| `examples/teochew/exp/`、`tensorboard/` | ❌ | 训练产物，被忽略 |

**关键**：`git clone` 之后，`examples/teochew/` 里只有 `conf/`、`local/`、`run_train.sh`（约 24 KB），
**没有 parquet 数据，也没有模型**，直接跑 `run_train.sh` 会报文件不存在。

| **合计** | | **9.75 GB** | **6.40 GB** | 省 3.35 GB |

来源与落地路径：

```python
# 官方 README 给出的 id（注意后缀 -2512）
snapshot_download('FunAudioLLM/Fun-CosyVoice3-0.5B-2512',
                  local_dir='pretrained_models/Fun-CosyVoice3-0.5B')
```

**为什么必须走 ModelScope**：当前机器实测 `huggingface.co` **不通**（超时），`modelscope.cn` 通。
脚本默认走 ModelScope，并开 8 线程分块下载（`max_workers=8`）+ 断点续传。
HF 镜像站（`hf-mirror.com`）也可用，但 id 要去掉 `-2512` 后缀：`FunAudioLLM/Fun-CosyVoice3-0.5B`。

## 4. 明确**不要**下载的

| 模型 | 为什么不用下 |
|---|---|
| `iic/CosyVoice2-0.5B` | `example.py` 的旧示例用，潮汕话微调链路完全不碰 |
| `iic/CosyVoice-300M` / `-SFT` / `-Instruct` | 同上，CosyVoice 1.x 时代产物 |
| `iic/CosyVoice-ttsfrd` | **可选**。`cosyvoice/cli/frontend.py:56-75` 是 `try: import ttsfrd / except: 回退 wetext`，没装也能跑 |
| `llm.rl.pt` | 只有做 RL 训练才要，slim 模式已排除 |
| `flow.decoder.estimator.fp32.onnx` | 只在 `load_trt=True` 时加载，slim 模式已排除 |

官方 README §Model download 列了 6 个 `snapshot_download`，**你只需要第 1 个**。
照抄 README 全下 = 多花 10+ GB 和大量时间。

## 5. git 拿不到的训练数据（0.73 GB）

| 内容 | 大小 | 处理方式 |
|---|---|---|
| `teochew-data/` 原始 wav（1331 个） | 257 MB | 传 `wav.zip`（205 MB）更快，或直接传目录 |
| `teochew-data/new_chaoshan` + meta | 16 MB | 同上 |
| `examples/teochew/data/{train,cv}/parquet/*.tar` | **243 MB** | **二选一**：① 直接传；② 传原始 wav 后重跑 `local/prepare_data.py` 生成 |

生产 parquet 的命令（新机器上）：

```bash
cd $COSYVOICE_ROOT/examples/teochew
python local/prepare_data.py --src_dir <teochew-data目录> --des_dir data
# 跑完会得到 data/train.data.list、data/dev.data.list 和两级 parquet
```

> `train.data.list` 里存的是**相对路径** `data/train/parquet/parquet_000000000.tar`，
> 所以必须让 `examples/teochew/` 作为工作目录（`run_train.sh` 已经做了 `cd "$(dirname "$0")"`）。

## 6. Python 环境

### 6.1 现状：`requirements.txt` 和实际环境**对不上**

实际跑通的环境是 `/root/autodl-tmp/envs/cosyvoice`（6.7 GB，153 个包），但和仓库里的
`requirements.txt` 差异很大：

| 包 | requirements.txt | 实际环境 |
|---|---|---|
| `numpy` | 1.26.4 | **2.2.6** |
| `modelscope` | 1.20.0 | **1.40.1** |
| `onnx` | 1.16.0 | **1.23.0** |
| `librosa` | 0.10.2 | **0.11.0** |
| `diffusers` | 0.29.0 | **0.39.0** |
| `transformers` | 4.51.3 | 4.51.3 ✓ |
| `torch` | 2.3.1 | 2.3.1+cu121 ✓ |
| `wetext` | 0.0.4 | **0.1.8** |
| `x-transformers` | 2.11.24 | **2.17.10** |

**别照 `requirements.txt` 装**，会装出另一个不兼容的组合。真实快照已存到：

```
docs/env_cosyvoice_pip_freeze.txt   (153 行，pip freeze 原样)
```

### 6.2 方案 A（推荐）：复刻跑通的环境

```bash
# 注意 -p 装到数据盘，避免占系统盘
conda create -p /root/autodl-tmp/envs/cosyvoice python=3.10 -y
PY=/root/autodl-tmp/envs/cosyvoice/bin/python

# 1) torch 走 PyTorch 官方 cu121 源
$PY -m pip install torch==2.3.1 torchaudio==2.3.1 \
    --index-url https://download.pytorch.org/whl/cu121

# 2) 其余依赖走清华源（torch 已装好，pip 会跳过）
grep -viE "^torch" docs/env_cosyvoice_pip_freeze.txt > /tmp/req.txt
$PY -m pip install -r /tmp/req.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 3) onnxruntime-gpu 若失败，用 NVIDIA 的 CUDA12 专用源补
$PY -m pip install onnxruntime-gpu \
    --extra-index-url https://aiinfra.pkgs.visualstudio.com/PublicPackages/_packaging/onnxruntime-cuda-12/pypi/simple/
```

装到 `/root/autodl-tmp/envs/cosyvoice` 有个额外好处：`examples/teochew/run_train.sh`
里的 `BIN="${BIN:-/root/autodl-tmp/envs/cosyvoice/bin}"` **正好指向这里**，不用改脚本。

### 6.3 方案 B：复用镜像自带的 py3.12 + torch 2.5.1

省下 ~2.5 GB 的 torch 下载，但**未验证**（torch 2.5→2.6 之间 `torch.load` 的
`weights_only` 默认值变过，CosyVoice 大量用 `torch.load` 加载 `.pt`）。
要试的话先跑 `python -c "import torch; print(torch.__version__)"` 确认，再补装缺的包。
**时间紧就选 A。**

## 7. 完整操作步骤

### 步骤 0 · SSH 凭据（新机器上）

新机器没有密钥，`git clone git@github.com:` 会 `Permission denied`。二选一：

```bash
# 方式一：把老机器的私钥拷过来（能直接复用）
#   在【老机器】上: cat /root/.ssh/id_ed25519
#   在【新机器】上写入 /root/.ssh/id_ed25519 并 chmod 600

# 方式二：新机器重新生成，再把公钥加到 GitHub
ssh-keygen -t ed25519 -C "feipengshao@163.com" -f /root/.ssh/id_ed25519 -N ""
cat /root/.ssh/id_ed25519.pub     # → https://github.com/settings/ssh/new
```

### 步骤 1 · 拉代码

```bash
cd /root/autodl-tmp
git clone -b dev git@github.com:feelins/CosyVoice.git
cd CosyVoice

# 子模块（必需）
git submodule update --init --depth 1 third_party/Matcha-TTS
# 国内慢的话用镜像：
# git -c url."https://gitclone.com/github.com/".insteadOf="https://github.com/" \
#     submodule update --init --depth 1 third_party/Matcha-TTS

export COSYVOICE_ROOT=/root/autodl-tmp/CosyVoice
```

### 步骤 2 · 装环境

见 §6.2。

### 步骤 3 · 下模型（9.75 GB）

```bash
bash scripts/setup_new_server.sh full      # 含自动校验
# 空间紧张就 slim（6.40 GB）
```

### 步骤 4 · 传训练数据（0.73 GB）

```bash
# 新机器上准备好目录后，从老机器传（或经本地上传）
# 传原始 wav：
/root/autodl-tmp/teochew-data/  →  /root/autodl-tmp/teochew-data/
# 然后生成 parquet：
cd $COSYVOICE_ROOT/examples/teochew && python local/prepare_data.py --des_dir data

# 或者（更省事，但要传 243 MB parquet）：
/root/autodl-tmp/CosyVoice/examples/teochew/data/  →  同名路径
```

### 步骤 5 · 开训

```bash
cd $COSYVOICE_ROOT/examples/teochew
bash run_train.sh
```

`run_train.sh` 里的关键路径（如目录不同需改脚本或设环境变量）：

```bash
PRETRAIN="${PRETRAIN:-/root/autodl-tmp/CosyVoice/pretrained_models/Fun-CosyVoice3-0.5B}"
BIN="${BIN:-/root/autodl-tmp/envs/cosyvoice/bin}"
```

32 GB 显存下，注释里说的「12GB 会 OOM」问题应该消失，但**显存大了不等于 batch 能随便加** ——
`examples/teochew/conf/cosyvoice3.yaml` 里的 batch 相关参数要不要调，建议先原样跑通一次再动。

## 8. 磁盘规划

| 盘 | 容量 | 放什么 | 预计占用 |
|---|---|---|---|
| 系统盘 `/` | 30 GB | 系统 + miniconda 本体 | ~10 GB |
| 数据盘 `/root/autodl-tmp` | 50 GB | 全部项目内容 | ~25 GB |

数据盘明细：


## 10. 踩坑清单

| # | 坑 | 应对 |
|---|---|---|
| 1 | 照抄 README 下 6 个模型 → 多花 10+ GB | 只下 `Fun-CosyVoice3-0.5B-2512` 一个 |
